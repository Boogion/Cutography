5 · Cut it

The preview shows each sheet drawn from the cut file itself (the Cut file tab shows all sheets together). Every export below uses those same outlines.

reopen it later from step 2
In Cricut Design Space
  1. Upload → Upload image → Browse, pick the .svg, choose Cut image, Upload, Add to canvas.
  2. With it selected, set W to the sheet width from the cut sheet below (lock on), then Ungroup once.
  3. Make It. Each color gets its own mat. Load that cardstock and use the material setting from the cut sheet.
  4. Cut every mat, then glue the sheets bottom to top. Every sheet shares the same 8.5 × 11 frame, so they line up.
Want it printed instead of layered? Upload the Print Then Cut image as an image (Complex), and Design Space will print it and cut the outline on white cardstock, up to 7.44 × 9.94 in on the Joy Xtra.
